# เสียงเฉลยภาษาไทย — ชุด days

วางไฟล์เสียงอัด (mp3) ไว้ในโฟลเดอร์นี้ ตั้งชื่อตามตารางนี้ แล้วเกมจะเล่นไฟล์เสียงแทนเสียงไทยของเครื่องโดยอัตโนมัติ
ถ้ายังไม่มีไฟล์ เกมจะใช้เสียงภาษาไทยของเครื่อง (หรือแสดงคำแนะนำ ถ้าเครื่องไม่มีเสียงไทย)

| ไฟล์ | คำ | คำไทย |
|---|---|---|
| `monday.mp3` | Monday | วันจันทร์ |
| `tuesday.mp3` | Tuesday | วันอังคาร |
| `thursday.mp3` | Thursday | วันพฤหัสบดี |
| `friday.mp3` | Friday | วันศุกร์ |
| `sunday.mp3` | Sunday | วันอาทิตย์ |

หลังเพิ่มหรือเปลี่ยนไฟล์ ให้เพิ่มค่า `ASSET_V` ใน `src/lib/assets.js` เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
