# 🌤️ Weather Cards (การ์ดคำศัพท์สภาพอากาศ)

เกมการ์ดคำศัพท์ภาษาอังกฤษสำหรับเด็กอนุบาล 2-3 ขวบ เล่นบนเว็บ ไม่ต้องติดตั้งหรือ build

## วิธีเล่น
1. เริ่มเกมจะมีการ์ดคว่ำ 5 ใบ (เห็นแค่หลังการ์ด) และการ์ดจะถูกสับ
2. จิ้มเลือกการ์ด 1 ใบ แล้วเกมจะสุ่มว่าได้คำไหน จากนั้นการ์ดจะพลิกขึ้น (หรือกด 🎲 **สุ่มให้**)
3. เกมสะกดตัวอักษรทีละตัว **S‑U‑N‑N‑Y** แล้วอ่านคำว่า **sunny** จากนั้นขึ้นว่า 🎤 พูดตามนะ
4. กด 🇹🇭 **แปล** (หรือแตะแถบชมพูบนการ์ด) ป้ายคำไทยจะเปิดออก และเกมอ่านว่า “แปลว่า แดดจ้า”
5. แตะตัวอักษรแต่ละตัวเพื่อฟังทีละตัว, 🔤 สะกดอีกครั้ง, 🔊 ฟังคำ
6. เปิดครบ 5 ใบได้ 🎉 แล้วกด 🔁 เล่นอีกครั้ง (🔀 สับการ์ด = เริ่มรอบใหม่)

| คำ | แปล |
|---|---|
| sunny | แดดจ้า |
| cloudy | มีเมฆมาก |
| windy | ลมแรง |
| rainy | ฝนตก |
| snowy | หิมะตก |

## เปิดเล่น
`python3 -m http.server` แล้วเข้า http://localhost:8000 หรือใช้ GitHub Pages (มี workflow ใน `.github/workflows/pages.yml`)

เสียงใช้ Web Speech API ของเครื่อง: เสียงอังกฤษ (en‑US) และเสียงไทย (th‑TH)
iPad/iPhone/Android/macOS มีเสียงไทยในตัว ส่วน Windows ใช้ Edge จะได้เสียงไทย (Chrome บน Windows อาจไม่มีเสียงไทย)

## โครงสร้าง
- `cards/*.webp` ภาพการ์ด 5 ใบ + `back.webp` หลังการ์ด (1200×1680)
- `design/cards.js` ต้นฉบับ SVG ของการ์ด, `design/cards.html` หน้าพรีวิว, `node design/render.js` สร้างไฟล์ .webp ใหม่
- `js/words.js` รายการคำศัพท์, `js/speech.js` เสียงอ่าน + เอฟเฟกต์, `js/game.js` ตัวเกม, `css/style.css`
- `fonts/` ฟอนต์ Fredoka + Mitr (SIL OFL)

เพิ่มคำใหม่: ใส่คำใน `WORDS` ของทั้ง `design/cards.js` (พร้อมฉาก) และ `js/words.js` แล้วรัน `node design/render.js`
