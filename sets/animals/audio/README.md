# เสียงเฉลยภาษาไทย — ชุด animals

วางไฟล์เสียงอัด (mp3) ไว้ในโฟลเดอร์นี้ ตั้งชื่อตามตารางนี้ แล้วเกมจะเล่นไฟล์เสียงแทนเสียงไทยของเครื่องโดยอัตโนมัติ
ถ้ายังไม่มีไฟล์ เกมจะใช้เสียงภาษาไทยของเครื่อง (หรือแสดงคำแนะนำ ถ้าเครื่องไม่มีเสียงไทย)

| ไฟล์ | คำ | คำไทย |
|---|---|---|
| `fish.mp3` | fish | ปลา |
| `lion.mp3` | lion | สิงโต |
| `tiger.mp3` | tiger | เสือ |
| `snake.mp3` | snake | งู |
| `bird.mp3` | bird | นก |

หลังเพิ่มหรือเปลี่ยนไฟล์ ให้เพิ่มค่า `ASSET_V` ใน `js/core/sets.js` เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
